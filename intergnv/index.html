Build notes

This prototype is not private. All of the demo data sits in one public file, data.json, which anyone can open in a browser. The player code only filters what is shown on screen; it does not protect anything. That is acceptable here only because every record is fake. Real player data must not be loaded until a server-side access check exists (see below).

The problem it addresses

Tournament availability is collected with online forms. There is no confirmation email, and new versions of a form go out during the season, so a family can believe they responded while the record shows the player as unavailable because a later version was never filled in.

The form on this page

  • Families answer here instead of on a separate form. They pick the player from the roster, so there is no typed name to mismatch, and they get a confirmation with a time and reference number immediately.
  • The page always shows the one answer that counts for each tournament, so there is no question of which version of a form was filled in.
  • In this demo nothing is saved. An answer updates the page in your browser only and disappears when you reload.

Where the records would come from

  • Answers made on this page would be stored directly. Answers still arriving through Google Forms or Microsoft Forms would be merged in by the team manager from the response spreadsheets.
  • The page shows when the records were last updated, so nobody mistakes an old snapshot for the current state.

Matching responses to players

Forms that ask only for a typed name and birth year make matching fragile: one typo can make a submitted answer look like "Not submitted". Each row records what it was matched on so mismatches are visible.

Planned access for real data

  • Team roster and form: visible only to the U19 team's families after logging in with Cloudflare Access (email one-time code, list kept by the team manager).
  • Saving answers and the player lookup: a Cloudflare Pages Function checks the request on the server and reads or writes Cloudflare KV.
  • Records live in KV, not in a public file, so nobody outside the team can download them.
