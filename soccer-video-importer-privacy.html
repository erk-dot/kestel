Overview

Soccer Video Importer (“the app”) is a desktop app that runs entirely on the user's own computer. This policy explains what Google user data the app accesses and what it does with it.

Google data the app accesses

With the user's permission, the app uses the Google Drive API to list the folders and files inside the Drive folder the user chooses for match videos, to create match folders there, and to upload video and photo files from the user's computer into those folders. To confirm an upload finished correctly, it reads each uploaded file's name, size and checksum.

How the data is used

This information is used only to decide which files still need uploading and to carry out those uploads. The app does not use Google data for advertising, analytics, profiling or any purpose other than the uploads the user starts.

Storage

The sign-in token Google issues is stored only on the user's computer, in the local configuration of the rclone tool the app uses. The app keeps its activity log and upload progress on that same computer. Nothing is sent to the developer or to any server other than Google's.

Sharing

The app does not sell, share or transfer Google user data to anyone. No human reads it.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Users can remove the app's access at any time at myaccount.google.com/permissions. Deleting the app's configuration from the computer removes the stored token.
